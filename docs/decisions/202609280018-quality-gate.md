# 18. Quality gate

Status: Accepted (2026-09-28)

## Context

Several people and AI agents change this repo in small steps. Each must leave it in a known-good state. With
separate lint, security and test commands, someone eventually skips one ("the specs passed"), and a lint or
security regression lands. There is no hosted CI for this exercise, so the gate has to run locally, in the
container.

## Chosen

`bin/ci` (Rails 8.1 `ActiveSupport::ContinuousIntegration`, steps in `config/ci.rb`) is **the** gate:

1. Setup (`bin/setup --skip-server`)
2. Style: RuboCop with the rails, rspec, performance and factory_bot plugins, `NewCops: enable`
3. Security: bundler-audit
4. Security: Brakeman (`--exit-on-warn`)
5. Tests: prepare the test DB
6. Tests: RSpec

Run it with `docker compose exec web bin/ci`. A change is done only when it is green.

## Discarded (why)

- **Separate commands per agent**: easy to skip one.
- **No security scans**: a vulnerable gem or an obvious injection would only be caught in review.

## Consequences

- One command to document and one command to check before every commit.
- `.rubocop.yml` is owned by the user. Rules are changed only after asking, not to make the gate pass.
